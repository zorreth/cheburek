Funny bot for Discord servers

## Features

1. Random replies with AI-generated messages.

## Configuration

Rename `.env.example` to `.env` and edit it, then use this command to register slash commands for your bot:

```sh
$ bun run register-commands
```

## Start

```sh
$ bun run start
```
