Cheburek
</h1>

Semi-random text generation bot for Discord servers. Assembles text based on previous messages.

## Configuration

Rename `.env.example` to `.env` and edit it, then use this command to register slash commands for your bot:

```sh
$ bun run register-commands
```

## Start

```sh
$ bun run start
```
